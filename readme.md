# Bumblebot Trainer

This is the official trainer used for the Bumblebot chess engine. It is designed to train strong models.

## Current status

The trainer is currently in development and is subject to breaking changes. The code is not yet stable, but here is what is currently implemented:
- self-supervised learning (adapted from JEPA 2-AC)
- p/v sl on lc0 and stockfish labeled data.
- p sl on lichess puzzles
- ssl on lichess games
